# SPAM DETECTION using BERT

Difficulty: Beginner to intermediate
Time: 3–4 days

Goal: Classify messages as spam or legitimate messages.

Example:

Input:
Congratulations! You've won a free prize. Click here to claim it.

Output:
Prediction: Spam

Dataset: UCI SMS Spam Collection

What you'll learn:
- Binary text classification
- Handling imbalanced datasets
- Choosing an appropriate decision threshold
- Precision versus recall
- Confusion matrices
- Comparing BERT with traditional machine learning models
Advanced challenge: Compare three approaches:
1. TF-IDF + Logistic Regression
2. Frozen pretrained BERT embeddings + Logistic Regression
3. Fine-tuned BERT
This comparison is particularly valuable because it teaches you when a Transformer actually improves performance over simpler approaches.

Deliverable: A spam detector with a simple user interface.
